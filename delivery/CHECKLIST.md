# Delivery checklist

## Start

- [ ] Confirm the project brief, scope, payment terms, owner, and success criteria.
- [ ] Collect the necessary inputs and approved access.
- [ ] Agree milestones and update cadence.

## Deliver

- [ ] Build the smallest useful deliverable.
- [ ] Check it against the agreed acceptance criteria.
- [ ] Review with the customer and record decisions.
- [ ] Resolve issues or agree any scope changes.

## Handover

- [ ] Get acceptance of the deliverables.
- [ ] Provide instructions, ownership, and support details.
- [ ] Transfer or revoke access as appropriate.
- [ ] Confirm final billing and remaining commitments.
- [ ] Record lessons for the next project.
