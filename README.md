# Scaffold Lite

A small, plain Markdown operating system for a business or client project.
Five folders, a few working templates, and no software to install.

## Start in 10 minutes

1. Make your own copy: use GitHub's **Use this template** if enabled, or download the repository ZIP into a new folder and initialize your own Git repo.
2. Fill in [company context](company/CONTEXT.md) and [the offer](company/OFFER.md).
3. Pick one goal in [the plan](operations/PLAN.md), then add the next actions to [tasks](operations/TASKS.md).
4. Use the other templates as needed. Delete anything you do not use.

If you clone this repository instead, replace its `origin` with your own repository before pushing project work.

## Where things go

| Folder | What it holds |
| --- | --- |
| [company](company/CONTEXT.md) | Who you serve, what you sell, and how you communicate |
| [marketing](marketing/PLAN.md) | Audience, campaigns, content, and the website |
| [sales](sales/PIPELINE.md) | Prospects, outreach, discovery, and proposals |
| [delivery](delivery/PROJECT.md) | Project scope, onboarding, delivery, and handover |
| [operations](operations/PLAN.md) | Goals, tasks, meetings, decisions, money, and weekly review |

## A simple weekly routine

- Start the week: choose one outcome and the three most useful tasks.
- During the week: keep tasks and the sales pipeline current; record decisions as they happen.
- End the week: write the weekly review and choose what to continue, change, or stop.

Start with Markdown. Use a spreadsheet or task app only when it solves a real problem, and link it from the relevant file. Keep one authoritative tracker for each kind of information.

## Before using this for real work

This repository is public. Keep client work in a separate private copy. Put sensitive notes, customer data, financial records, and credentials in access-controlled tools; an ignored file is not an access boundary.

## About this version

Derived from a larger company operations scaffold and rewritten as a small documentation-only starter. The original scaffold is maintained separately. See [what changed](SIMPLIFIED.md).

There are no connected accounts, automations, deployments, paid services, or application dependencies. Templates contain prompts, not established company facts.
