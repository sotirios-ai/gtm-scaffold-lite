# What changed

The larger scaffold was copied, then reduced to these standalone Markdown templates.

| Larger operating area | Simplified home |
| --- | --- |
| Internal operations and brand | company/ and operations/ |
| Marketing, content, newsletter, and creator programs | marketing/ |
| Copywriting and sales | sales/ |
| Service operations | delivery/ |
| Finance, reporting, and team projects | operations/ |
| Website, platform, inbox integration, and research applications | Document the need in marketing/ or delivery/; add software only when needed |

Removed from this copy: application code, generated indexes, tool-specific skills and hooks, deployment configuration, historical examples, brand assets, research archives, and original Git history.

Kept in simpler form: company context, positioning, evidence-based messaging, prospect tracking, delivery scope, owners, next actions, decision records, and weekly review.

This public version contains only the rewritten starter documents and .gitignore. The source repository was not modified. No rights to omitted third-party code or assets are granted by this template.
